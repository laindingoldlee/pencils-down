# Signal Salvage art

Drop files in this folder and they replace the placeholders after the next deploy. No code changes needed.
Names are lowercase with dashes. SVG, PNG, WebP, JPG or GIF.

| File name | What it is | Size |
|---|---|---|
| `shield`, `grapple`, `pulse`, `key`, `vault`, `map`, `predictor`, `breach`, `leviathan`, `aurora` | The ten emblem pictures, shown in the middle of each card | Square, 256×256 or bigger, transparent background |
| `back` | The back of a face-down card (the scanning deck) | Portrait, about 500×700 |
| `background` | The table behind everything | About 1920×1080, dark |
| `logo` | The title in the game's top bar | Transparent, wide |
| `crew` | The Starting Crew card, shown when the first player is picked | Any |
| Specialists: `leviathan-tamer`, `grapple-expert`, `aurora-collector`, `black-box-custodian`, `void-angler`, `prism-analyst`, `failsafe-engineer`, `archive-navigator`, `pulse-commander`, `backfire-specialist`, `deep-scanner`, `breach-interceptor`, `data-raider`, `safe-route-planner`, `scrap-diver`, `breach-specialist`, `archive-multiplier` | Specialist portraits | Square |
| Mission Protocols: `signal-thieves`, `total-recovery`, `first-to-fifty`, `full-spectrum`, `pattern-lock`, `under-the-limit`, `bottom-shelf` | Small badges | Square |

Example: `shield.svg`, `back.png`, `void-angler.webp`.
